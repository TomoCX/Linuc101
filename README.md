# Linuc レベル1 101 問題演習

ブラウザだけで動く選択式の問題演習アプリです。インストールやサーバは不要です。

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけです。

## PCとiPhoneで進捗を同期する

進捗はブラウザごとに保存されるため、そのままでは端末をまたげません。ホーム画面の
**「進捗の同期・バックアップ」** から手動で受け渡します。現在のセッション・累計成績・設定がまとめて移ります。

> **使い終わった端末で「書き出す」→ 次に使う端末で「読み込む」** の順に操作してください。
> 逆順にすると新しい記録が古いもので上書きされます（そうなりそうな場合は警告が出ます）。

### 方法1：ファイルで受け渡す

1. 使い終わった端末で **「ファイルに書き出す」** → `linuc101-progress-YYYYMMDD-HHMM.json` がダウンロードされる
2. そのファイルを iCloud Drive や OneDrive に保存する
3. 次に使う端末で **「ファイルから読み込む」** → クラウド上のファイルを選ぶ

### 方法0：自動同期（GitHub Gist）★おすすめ

一度設定すれば、以降は操作不要で両端末の進捗がそろいます。

**準備（各端末で1回ずつ）**

1. https://github.com/settings/tokens/new?scopes=gist&description=Linuc101 を開く
   （権限は **`gist` だけ** にチェック。有効期限は「No expiration」にしておくと入れ直しが不要です）
2. 発行された `ghp_...` をコピー
3. アプリの「自動同期（GitHub Gist）」欄に貼り付けて **接続する**

1台目で接続すると非公開のGistが自動で作られ、2台目で同じトークンを入れると**その保存先を自動で見つけて**つながります。Gist ID を控える必要はありません。

**動作**

| タイミング | 動き |
|---|---|
| アプリを開いたとき | GitHub側が新しければ自動で取り込む |
| 他のアプリから戻ったとき | 同上 |
| 解答するたび | 3秒後にまとめてGitHubへ保存 |
| 「今すぐ同期」ボタン | 手動で同期 |

新旧は最終変更時刻で判定し、**新しい方が残ります**。同時に使わない限り競合しません。

> 🔑 トークンはその端末のブラウザ（localStorage）にのみ保存され、リポジトリには一切含まれません。共有PCでは使わないでください。不要になったら「接続を解除」、またはGitHubの Settings → Developer settings → Personal access tokens で削除できます。
> 通信できないときは自動的にローカル保存のみで動作し、次回接続時に同期されます。

### 方法2：同期コードで受け渡す

1. **「同期コードをコピー」** を押す（クリップボードにコピーされます）
2. メモアプリやチャットで自分宛てに送る
3. 次に使う端末で **「同期コードから読み込む」** → 貼り付けて「この内容を読み込む」

読み込み時には、双方の書き出し日時と累計解答数を表示した確認ダイアログが出ます。

## iPhone / iPad で使う

スマホの画面幅に合わせたレイアウトになっているので、そのまま使えます。持っていく方法は3通りあります。

### 方法A：1ファイル版を iCloud Drive に置く（いちばん手軽）

1. `build-single-file.ps1` を右クリック →「PowerShell で実行」
2. できた **`LinuC101-1file.html`** を iCloud Drive（または Google Drive / Dropbox）へコピー
3. iPhone の「ファイル」アプリでタップして開く

全部入りの1ファイルなので、これだけコピーすれば動きます。問題を追加したらスクリプトを再実行してください。

> ⚠️ この方法（`file://` で開く場合）は、Safari が進捗や累計成績を保存できないことがあります。1回分の演習には問題ありませんが、記録を残したい場合は方法B・Cを使ってください。

### 方法B：Webに置いて「ホーム画面に追加」（おすすめ）

GitHub Pages などの静的ホスティングにフォルダごと置き、Safari で開いて共有ボタン →「ホーム画面に追加」。
アドレスバーのないアプリのような表示で起動し、進捗・累計成績もきちんと保存されます。

### 方法C：PCでサーバを立てて同じWi-Fiから開く

PCのこのフォルダで下記を実行し、iPhoneのSafariで `http://<PCのIPアドレス>:8000/` を開きます（PCの電源が入っている間だけ使えます）。

```bash
python -m http.server 8000
```

### iPhone向けの対応内容

- ホーム画面に追加したときに全画面のアプリとして起動する（ステータスバーの色も合わせ）
- ノッチ・ホームバーを避けるセーフエリア対応
- 検索欄をタップしても画面が勝手に拡大しない（フォントサイズ16px）
- コマンド表がアドレスバーの分だけ切れないよう `100dvh` を使用
- 集計タイルは3列、上部の集計表示は非表示にして横スクロールが出ないよう調整
- ダブルタップ拡大・タップ時のハイライトを抑制、指で押しやすい選択肢の高さ
- タッチ端末では hover の色変化を出さない

## 重要度

すべての問題に重要度を設定しています。出題画面の右上にバッジで表示され、ホームの「重要度」で絞り込めます。

| 表示 | 意味 | 問題数 |
|---|---|---|
| ★★★ 必出 | 試験で繰り返し問われる、落とせない論点 | 67 |
| ★★ 重要 | 標準的な頻度で問われる | 62 |
| ★ 補足 | 知っていれば得だが優先度は低い | 14 |

**44セクションすべてに★★★の問題が1問以上**あります。時間がないときは「★★★のみ（必出）」で67問に絞って回すのが効率的です。

重要度は `questions-sec.js` の `IMPORTANCE`（問題ID → 1〜3）で設定します。指定がない問題は自動的に★★（重要）になります。

## 復習おすすめ（回答状況に応じた学習テキストの表示）

解いた結果から、**自力で正解できなかった項目**を洗い出して、その学習テキストをその場で開けるようにしています。

| 場所 | 判定のもと | 表示 |
|---|---|---|
| 結果画面「この結果から復習するとよい項目」 | 直前のセッション | 上位6項目（残りは件数のみ表示） |
| ホーム「いま復習すべき項目」 | 累計成績 | 上位5項目（残りは件数のみ表示） |

各項目には次が並びます。

- 主題・節の名前と**習得率**（その節の全問題のうち自力で正解できた割合。50%未満は赤、80%未満は黄）
- 内訳と習得状況のバー。**分母はその節の全問題数**です
  - ホーム：`全 7問中 1問 を自力で正解（うち◎連続 1問） ・ つまずき 4問 ・ 未着手 2問`
  - 結果画面：`この回で 6問 落とした（不正解 1 ・ 参照 3 ・ 未回答 2）` ＋ 累計の内訳（自力正解のうち◎連続正解が何問かも表示）
- **「学習テキストを開く」** — その節のノート本文（表・図解つき）をその場で展開
- **「この項目を解く（N問）」／「単語帳（N枚）」／「ノートで開く」**

問題ごとの状態は次の4つに分けています。

| 区分 | 意味 |
|---|---|
| 連続正解 | 2回以上つづけて自力で正解した（自力正解のうち、特に定着したもの） |
| 自力正解 | 一度でもコマンド表を見ずに正解した |
| つまずき | 解いたが、まだ自力正解できていない（不正解／参照つき正解のみ） |
| 未着手 | まだ一度も解答していない（スキップした問題もここ） |

並び順は、ホームが習得率の低い順（同率ならつまずきの多い順）、結果画面がその回で落とした数の多い順（同数なら習得率の低い順）です。

## 用語のクリック説明

解説文に出てくる用語（`iノード`、`パーミッション`、`ジャーナリング`、コマンド名など）には点線の下線が付き、**クリックすると意味がその場で表示**されます。出題直後の解説と、結果画面の解答一覧のどちらでも使えます。

- 読みやすさのため、同じ語は解説内の**最初の1か所だけ**リンクになります
- 画面が広いときはクリックした語の近くに、狭いときは画面下部のシートとして表示されます
- 閉じるのは × ／ 外側をクリック ／ `Esc`
- 用語は334語。`glossary.js` の手書き分に加え、単語帳（`cards.js`）とコマンド表（`commands.js`）から自動で補われます

説明を追加・修正するには `glossary.js` の `GLOSSARY` に `{ key: "用語", def: "説明" }` を足します。ここに書いた分が最優先されます。

## 単語帳

単語・コマンドとその意味を1枚ずつめくって覚えるモードです。画面上部の「単語帳」ボタン、またはホーム画面から開けます。**288枚**を44セクションに分けて収録しています。

- **1枚ずつ** — 表に単語、タップ（またはスペースキー）で意味を表示。カードごとに「覚えた」チェック
- **一覧** — 単語と意味を一覧で確認。同じくチェックできる
- **セクション選択** — セクション単位、主題まるごと、すべて、から選べる
- **シャッフル** — 並び順をランダムにする（ホームの「全部シャッフル」から直接開始も可能）
- **覚えたカードを隠す** — まだ覚えていないカードだけを繰り返す
- 進捗は「覚えた 12 / 54 枚（22%）」のように表示され、**同期の対象**になります

| キー | 動作 |
|---|---|
| `←` `→` | 前のカード／次のカード |
| `Space` | 意味の表示・非表示 |
| `Enter` | 「覚えた」の切り替え |

カードを追加・修正するには `cards.js` を編集します（`sec` はノートの節キーと共通）。

## 暗記ノート

出題範囲を主題ごとにまとめた学習ノートを内蔵しています。画面上部の「暗記ノート」ボタン、またはホーム画面の主題チップから開けます。

- 主題（1.01〜1.05）での絞り込みと、目次からのジャンプ
- ノート全文の検索
- **図解つき** — 覚えにくい箇所には SVG の図を自動で挿入します
- **「覚えた」チェック** — 節ごとにチェックでき、「覚えた 12 / 46 項目（26%）」のように進捗が出ます。「覚えていない項目だけ表示」で未習の節に絞り込めます
- **節ごとの出題** — 各節の「問題を解く（N問）」でその範囲だけを演習でき、終わったら「ノートに戻る」で元の位置に戻れます

「覚えた」チェックも、進捗の同期・バックアップの対象に含まれます（PC・iPhone間で引き継がれます）。

| 図解のある項目 |
|---|
| OSとカーネル・シェルの階層 ／ 起動の流れとブートプロセス ／ systemdのターゲットとランレベル |
| パーミッションの読み方 ／ SUID・SGID・スティッキービット ／ iノードとリンク ／ FHS |
| パイプとリダイレクト ／ ジョブの状態遷移 ／ viのモード遷移 |
| パーティション（MBR / GPT） ／ マウントの考え方 |

### ノートを書き換えるには

`LinuC101_暗記まとめ.md` を編集し、次を実行して `notes.js` を作り直します。

```bash
powershell -ExecutionPolicy Bypass -File build-notes.ps1
```

図解を追加・変更する場合は `notes-view.js` の `NOTE_FIGURES` に、**見出し名をキーにして** SVG を書きます。その見出しの直後に自動で挿入されます。色は `.fig` のCSSクラス（`bx` `bx-a` `bx-g` `bx-w` `bx-r` `lbl` `mono`）を使うと、アプリのテーマに追従します。

## 機能

- **出題数を選べる** — 5 / 10 / 20 / 30 / 50 / 全問
- **カテゴリで絞り込み** — 主題1.01〜1.05を個別に選択
- **重要度で絞り込み** — すべて／★★以上／★★★のみ（必出）
- **出題順** — ランダム / 番号順
- **弱点優先** — 累計成績で不正解率が高い問題から出題（◎連続正解まで届いた問題は後回し）
- **即時解説** — 選択肢を選んだ直後に、正解・不正解にかかわらず正解と解説を表示。解説内のオプションには（英単語＝意味）の形で覚え方を併記
- **用語のクリック説明** — 解説中の用語には点線が引かれ、クリック（タップ）するとその場で意味が出る
- **「不正解にする」ボタン** — 正解した問題を自分の判断で不正解として記録できる（まぐれ当たりの除外用）。押した後は「やっぱり正解にする」で戻せる
- **「正解（参照）」** — 解答前にコマンド表を開いた問題で正解した場合は、灰色の「○ 正解」として自力の正解とは別枠で記録される
- **「◎ 連続正解」** — 同じ問題を2回以上つづけて（コマンド表を見ずに）正解すると、「○ 正解」の上のランクとして金色で表示される。1回でも間違える／参照して正解すると連続はリセットされる
- **スキップ** — 解答せず次へ進める（未回答としてカウント）
- **ホーム画面の進捗表示** — 全何問中、正解／不正解／未回答が何問かをバーと数値で表示
- **結果画面** — 正答率、全問の解答一覧（クリックで解説を展開）、間違えた問題だけ再挑戦
- **累計成績** — カテゴリ別の解答数・正解数・参照数・◎連続正解数・正答率
- **到達ランク** — 問題ごとに `－未着手` → `△つまずき` → `○正解` → `◎連続正解` の4段階。累計成績の「◎連続」列と、復習おすすめの金色のバーで、どれだけ定着したかを確認できる
- **コマンドオプション早見表（右側ヘルプパネル）** — 下記参照
- **Claudeにコピー** — いま開いている問題・ノート・単語帳の内容を、そのままClaudeに貼れる形でコピー。スマホでは押すと同時にClaudeアプリが開く（通信・費用なし）

進捗と成績はブラウザの localStorage に保存されるため、閉じても「続きから再開」できます。

## コマンドオプション早見表

次のいずれの方法でも開けます。どの画面（ホーム／出題中／結果）でも利用でき、解答中でも開いたままにできます。

- 問題カード内の「コマンド表を開く」ボタン（解答前は「コマンド表を開く（不正解扱い）」と赤く表示）
- 画面右端の「コマンド表」タブ
- 画面右上の「コマンド表」ボタン
- `H` キー（`Esc` で閉じる）

パネル上部の「**次の問題でも開いたままにする**」チェックボックスで、次の問題へ進んだときの挙動を選べます。

| 状態 | 動作 |
|---|---|
| チェックあり（既定） | 開いたまま次の問題へ進む。そのため次の問題も参照扱い（不正解）になる |
| チェックなし | 次の問題へ進むと自動的に閉じる。開き直さない限り通常どおり採点される |

表は次の3列構成です。

| 入力するコマンド | 覚え方 | 実際の役割 |
|---|---|---|
| `-c` | create（作成） | 新しいアーカイブを作成する |
| `-x` | extract（取り出す） | アーカイブを展開する |
| `-f` | file（ファイル名） | 対象アーカイブのファイル名を指定 |

- **関連コマンドの自動表示** — 出題中にパネルを開くと、先頭に「この問題に関係するコマンド」として該当コマンドが**展開済み**で並びます（琥珀色で強調）。その下に「そのほかのコマンド」が続きます。問題を進めるたびに自動で入れ替わります。
- **検索** — コマンド名・オプション・覚え方・役割のどれでも部分一致で検索（日本語可）。一致箇所はハイライトされます。
- **グループ絞り込み** — ファイル操作／テキスト処理／パッケージ管理など11グループ。
- 検索中・グループ絞り込み中は関連セクションを出さず、通常の一覧を表示します。
- 画面幅が1250px以上のときは右側に固定表示され、問題を見ながら参照できます。狭い画面では引き出し（ドロワー）として開きます。

### 参照して正解したときの扱い（「正解（参照）」）

出題中にコマンド表を開くと、その問題には「コマンド表を参照しています。この問題は正解しても**「正解（参照）」**として、自力の正解とは分けて記録されます」という案内が出ます。

判定は次の5種類です。

| 表示 | 色 | 意味 |
|---|---|---|
| ◎ 連続正解 `N回つづけて自力正解` | 金色 | 2回以上つづけて自力で正解した問題（正解の上のランク） |
| ○ 正解 | 緑 | 参照せずに正解 |
| ○ 正解 `コマンド表を参照` | **灰色** | コマンド表を見て正解 |
| ✕ 不正解 | 赤 | 誤答（参照の有無は問わない） |
| ― 未回答 | 濃い灰色 | スキップ／未到達 |

- 正答率は「自力で正解した割合」です。参照つきの正解は分母に含まれますが、正解としては数えません。
- ホーム・出題画面・結果画面のカウンタと進捗バーに、灰色の「正解（参照）」が独立して表示されます。
- 「できなかった問題だけ再挑戦」の対象には、不正解・未回答に加えて参照つき正解も含まれます。
- 判定は問題単位です。次の問題に進むとリセットされます。
- 途中で閉じても、その問題を「参照した」事実は取り消せません。
- パネルを開いたまま次の問題へ進んだ場合、その問題も参照扱いになります。避けたい場合は「次の問題でも開いたままにする」のチェックを外してください。
- **解答した後に開く分には影響しません。** 解説を読みながら参照しても判定は変わりません。

コマンドを追加・修正する場合は `commands.js` を編集します。

```js
{
  name: "コマンド名", group: "テキスト処理",   // group は HELP_GROUPS のいずれか
  keys: ["リダイレクト"],                      // 任意。日本語で問題と結び付けたいとき
  desc: "コマンドの概要",
  ex: "実行例",
  rows: [
    { opt: "-n", memo: "number（番号）", role: "行番号を付ける" }
  ]
}
```

関連コマンドの判定は、コマンド名に含まれる英字（`tar`、`mkswap` など）と `keys` の日本語キーワードを、問題文・選択肢・解説と突き合わせて行います。問題文に出てくるものほど上位に並びます。`file.txt` のようなファイル名に反応しないよう、前後がピリオドの場合は一致とみなしません。

## Claudeにコピー（画面の内容を、そのまま貼れる形で書き出す）

**「Claudeにコピー」ボタンを押す → 開いたClaudeに貼り付ける → いちばん下に質問を書く**、それだけです。
スマホでは、押すと同時にClaudeアプリが開きます。
アプリ側は通信を一切しません。APIキーも料金も不要です。

### ボタンの場所

| 場所 | 動き |
|---|---|
| 出題画面の「Claudeにコピーして開く」 | **押すだけでコピー＋Claudeが開く**（パネルは開かない） |
| 上部のボタン・画面左端のタブ・`A` キー | パネルが開く。中身を確認し、質問を先に入れてからコピーできる |

### 押したらClaudeを開く

スマホでは、コピーと同時に **Claudeアプリが開きます**。
`https://claude.ai/new` が Claudeアプリの Universal Links（iOS）／App Links（Android）に
登録されているため、アプリが入っていればアプリが、入っていなければブラウザが開きます。

ホーム画面の設定で切り替えられます。

| 設定 | 動き |
|---|---|
| Claudeを開く（アプリがあればアプリ）※スマホの既定 | `https://claude.ai/new` を開く。いちばん確実 |
| Claudeアプリを直接開く | `claude://claude.ai/new` を開く。上でアプリが開かないときの予備（未インストールだとエラーになる） |
| 開かない（コピーだけ）※PCの既定 | コピーだけして、画面はそのまま |

設定を触らないかぎり、**スマホなら開く／PCならコピーだけ**を毎回その場で判定します。
PCで「開く」を選んだ場合は新しいタブで開くので、解いている画面はそのまま残ります。

### コピーされる内容

先頭に「LinuC 101の家庭教師として、最後の【質問】に答えてください」という指示が入り、
そのあとに画面ごとの情報が続き、最後が `## 質問` で終わります。
貼り付けたあと、その下に質問を書けばそのまま聞けます。

| 開いている画面 | 一緒にコピーされるもの |
|---|---|
| 出題中 | 問題文・選択肢・自分が選んだもの・判定・解説・その節のノート・関連するコマンド表・出てくる用語の意味 |
| 結果 | この回の成績と、落とした問題（問題文と正解つき） |
| 暗記ノート | いま画面に映っている節の本文（スクロールすると自動で切り替わる） |
| 単語帳 | 表示中のカードと意味、その節のノート |
| ホーム | 累計成績と、自力正解できていない問題が残っている節 |

長さはだいたい 500〜3000文字です。パネルには実際にコピーされる全文と文字数が表示されます。

### 質問をあらかじめ入れておく

パネルを開くと、画面に合わせた質問の候補（「なぜこの答えになるのか教えて」など）が並びます。
選ぶか自分で書くと、`## 質問` の下にその文が入った状態でコピーされるので、貼り付けるだけで済みます。

### 未解答の問題では正解を伏せる

まだ解答していない問題では、**正解と解説を外してコピー**します
（先頭の指示にも「ヒントを出してください」と書かれます）。
答えも一緒に渡したいときは、ホーム画面の設定で
「未解答の問題でも、正解と解説を含めてコピーする」をオンにしてください。

### 解答前のコピーは「参照」扱い

コマンド表と同じ考え方で、**解答する前にコピーすると、その問題は「正解（参照）」として記録**されます。
解答したあとのコピーは成績に影響しません。
設定の「解答前にコピーしたら『参照』扱いにする」で切り替えられます。

### アプリの中から探す（おまけ）

パネル下部の「アプリの中から探す」を開くと、コピーせずにその場でコマンド表・用語・ノートを検索できます。
通信しないので、オフラインでも1ファイル版でも使えます。

### コピーできなかったときは

ブラウザがコピーを許可しない場合（古い端末など）は、パネルが開いて枠が選択できる状態になります。
長押し（PCはドラッグ）で選んでコピーしてください。

## 問題を追加・修正するには

`questions.js` の `QUESTIONS` 配列に追記するだけです。

```js
{
  id: 97,                       // 他と重複しない数値
  cat: "1.03",                  // CATEGORIES のキー
  q: "問題文",
  choices: ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  answer: [1],                  // 正解のインデックス（0始まり）
                                //  要素1つ → 単一選択（クリックで即判定）
                                //  要素2つ以上 → 複数選択（「解答する」で判定）
  exp: "解説文"
}
```

カテゴリ自体を増やす場合は、同ファイル先頭の `CATEGORIES` にキーと名称を追加します。

## ファイルの構成（開発者向け）

読み込み順は `index.html` の末尾のとおりです。

```
core.js            土台：保存キー・状態・共通の道具（esc / shuffle / secTitle / show など）
  ↓
データ             questions.js / questions-sec.js / commands.js / notes.js / cards.js
  ↓
各画面             notes-view.js / cards-view.js / glossary.js / review-view.js
                   help-view.js / sync-view.js
  ↓
app.js             ホーム・出題・結果（最後に読み込み、末尾で初期化する）
```

- 状態（`session` `stats` `learned` `cardsLearned` `config` など）と保存処理は **core.js に一本化**しています。
- `save()` は進捗に関わるキーなら変更時刻を記録し、`onProgressSaved`（sync-view.js が設定）を呼びます。自動同期はこのフック経由なので、core.js は同期の実装を知りません。
- 文字列のエスケープは `esc()`、節キーの分解は `secTheme()` / `secTitle()`、チップ列は `bindChips()` / `selectChip()` に統一しています。
- `build-single-file.ps1` は `index.html` が読み込むファイルを順に埋め込み、**取り込み漏れがあればエラーで止まります**。新しいJSを足したら、この一覧にも追加してください。

## かんたんロック（パスワード画面）

初めての端末では、開いたときにパスワード入力を求めます。一度通した端末では次回から省略されます。

- 「この端末では次回から省略する」にチェックを入れて解除すると、その端末のブラウザに記録が残ります
- 記録はブラウザごとです。別のブラウザやプライベートウィンドウでは再度入力が必要です
- ホーム画面の一番下の「**ロックし直す**」で、その端末の記録を消せます（進捗は消えません）

### ⚠️ この仕組みで守れる範囲

このアプリは GitHub Pages 上の公開サイトで、動作はすべてブラウザ側です。したがって

- **できること** … URLを知らない人・知っている人が、そのまま中身を見るのを防ぐ
- **できないこと** … ページのソースや `questions.js` などを直接開かれるのは防げない

**知らない人がうっかり使うのを防ぐ用途に限った仕組み**です。本当に非公開にしたい場合は、リポジトリを非公開にしたうえで認証機能のあるホスティング（Netlify のパスワード保護、Cloudflare Access など）に置くか、公開せず1ファイル版だけを使ってください。

パスワードは平文では埋め込まず、`auth.js` に**ハッシュ（SHA-256を2万回繰り返したもの）だけ**を置いています。

### パスワードを変えるには

1. アプリを開き、ブラウザの開発者ツールのコンソールで次を実行する

```
makeAuthHash("新しいパスワード")
```

2. 表示された `const AUTH_HASH  = "...";` の行を、`auth.js` の同じ行と置き換える
3. 保存して push する

変更後は、各端末で1回だけパスワードの再入力が必要になります（古い記録は自動的に無効になります）。

## 暗記ノートの重要マーク

ノートのどこを優先して覚えるかが分かるよう、2種類の印を付けています。

### 節ごとの★（重要度）

各節の見出しに ★★★／★★／★ が付きます。★★★ の節は枠も琥珀色になります。

| 印 | 意味 | 節数 |
|---|---|---|
| ★★★ | 最重要。ここから手を付ける | 24 |
| ★★ | 重要 | 20 |
| ★ | 補足 | 2 |

「**★★★ の項目だけ**」にチェックを入れると、最重要の24節だけに絞り込めます（目次も連動します）。

### 本文中の重要語

「これは覚える」という語句に琥珀色のハイライトと ★ が付きます（98語・本文中182か所）。

- 数字（`666` `777` `4000` `127台` `2TB` `100MB` など）
- パス（`/etc/shadow` `~/.ssh/authorized_keys` `/proc/cpuinfo` など）
- 用語（`SUID` `スティッキービット` `iノード` `ハードリンク` `graphical.target` など）

「**重要語に印を付ける**」のチェックを外せば、ハイライトなしの素の状態で読めます。復習おすすめの「学習テキストを開く」で出る本文にも同じ印が付きます。

### 印を変えるには

`keypoints.js` を編集します。

- `NOTE_STARS` … 節キー（`"1.02/アクセス権（パーミッション）"` 形式）→ 1〜3。書いていない節は★★扱い
- `KEY_POINTS` … ハイライトする語句の配列。完全一致で拾うので、短く具体的な語を入れる
