# Linuc レベル1 101 問題演習

ブラウザだけで動く選択式の問題演習アプリです。インストールやサーバは不要です。

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけです。

## PCとiPhoneで進捗を同期する

進捗はブラウザごとに保存されるため、そのままでは端末をまたげません。ホーム画面の
**「進捗の同期・バックアップ」** から手動で受け渡します。現在のセッション・累計成績・設定がまとめて移ります。

> **使い終わった端末で「書き出す」→ 次に使う端末で「読み込む」** の順に操作してください。
> 逆順にすると新しい記録が古いもので上書きされます（そうなりそうな場合は警告が出ます）。

### 方法1：ファイルで受け渡す

1. 使い終わった端末で **「ファイルに書き出す」** → `linuc101-progress-YYYYMMDD-HHMM.json` がダウンロードされる
2. そのファイルを iCloud Drive や OneDrive に保存する
3. 次に使う端末で **「ファイルから読み込む」** → クラウド上のファイルを選ぶ

### 方法0：自動同期（GitHub Gist）★おすすめ

一度設定すれば、以降は操作不要で両端末の進捗がそろいます。

**準備（各端末で1回ずつ）**

1. https://github.com/settings/tokens/new?scopes=gist&description=Linuc101 を開く
   （権限は **`gist` だけ** にチェック。有効期限は「No expiration」にしておくと入れ直しが不要です）
2. 発行された `ghp_...` をコピー
3. アプリの「自動同期（GitHub Gist）」欄に貼り付けて **接続する**

1台目で接続すると非公開のGistが自動で作られ、2台目で同じトークンを入れると**その保存先を自動で見つけて**つながります。Gist ID を控える必要はありません。

**動作**

| タイミング | 動き |
|---|---|
| アプリを開いたとき | GitHub側が新しければ自動で取り込む |
| 他のアプリから戻ったとき | 同上 |
| 解答するたび | 3秒後にまとめてGitHubへ保存 |
| 「今すぐ同期」ボタン | 手動で同期 |

新旧は最終変更時刻で判定し、**新しい方が残ります**。同時に使わない限り競合しません。

> 🔑 トークンはその端末のブラウザ（localStorage）にのみ保存され、リポジトリには一切含まれません。共有PCでは使わないでください。不要になったら「接続を解除」、またはGitHubの Settings → Developer settings → Personal access tokens で削除できます。
> 通信できないときは自動的にローカル保存のみで動作し、次回接続時に同期されます。

### 方法2：同期コードで受け渡す

1. **「同期コードをコピー」** を押す（クリップボードにコピーされます）
2. メモアプリやチャットで自分宛てに送る
3. 次に使う端末で **「同期コードから読み込む」** → 貼り付けて「この内容を読み込む」

読み込み時には、双方の書き出し日時と累計解答数を表示した確認ダイアログが出ます。

## iPhone / iPad で使う

スマホの画面幅に合わせたレイアウトになっているので、そのまま使えます。持っていく方法は3通りあります。

### 方法A：1ファイル版を iCloud Drive に置く（いちばん手軽）

1. `build-single-file.ps1` を右クリック →「PowerShell で実行」
2. できた **`LinuC101-1file.html`** を iCloud Drive（または Google Drive / Dropbox）へコピー
3. iPhone の「ファイル」アプリでタップして開く

全部入りの1ファイルなので、これだけコピーすれば動きます。問題を追加したらスクリプトを再実行してください。

> ⚠️ この方法（`file://` で開く場合）は、Safari が進捗や累計成績を保存できないことがあります。1回分の演習には問題ありませんが、記録を残したい場合は方法B・Cを使ってください。

### 方法B：Webに置いて「ホーム画面に追加」（おすすめ）

GitHub Pages などの静的ホスティングにフォルダごと置き、Safari で開いて共有ボタン →「ホーム画面に追加」。
アドレスバーのないアプリのような表示で起動し、進捗・累計成績もきちんと保存されます。

### 方法C：PCでサーバを立てて同じWi-Fiから開く

PCのこのフォルダで下記を実行し、iPhoneのSafariで `http://<PCのIPアドレス>:8000/` を開きます（PCの電源が入っている間だけ使えます）。

```bash
python -m http.server 8000
```

### iPhone向けの対応内容

- ホーム画面に追加したときに全画面のアプリとして起動する（ステータスバーの色も合わせ）
- ノッチ・ホームバーを避けるセーフエリア対応
- 検索欄をタップしても画面が勝手に拡大しない（フォントサイズ16px）
- コマンド表がアドレスバーの分だけ切れないよう `100dvh` を使用
- 集計タイルは3列、上部の集計表示は非表示にして横スクロールが出ないよう調整
- ダブルタップ拡大・タップ時のハイライトを抑制、指で押しやすい選択肢の高さ
- タッチ端末では hover の色変化を出さない

## 暗記ノート

出題範囲を主題ごとにまとめた学習ノートを内蔵しています。画面上部の「暗記ノート」ボタン、またはホーム画面の主題チップから開けます。

- 主題（1.01〜1.05）での絞り込みと、目次からのジャンプ
- ノート全文の検索
- **図解つき** — 覚えにくい箇所には SVG の図を自動で挿入します
- **「覚えた」チェック** — 節ごとにチェックでき、「覚えた 12 / 46 項目（26%）」のように進捗が出ます。「覚えていない項目だけ表示」で未習の節に絞り込めます
- **節ごとの出題** — 各節の「問題を解く（N問）」でその範囲だけを演習でき、終わったら「ノートに戻る」で元の位置に戻れます

「覚えた」チェックも、進捗の同期・バックアップの対象に含まれます（PC・iPhone間で引き継がれます）。

| 図解のある項目 |
|---|
| OSとカーネル・シェルの階層 ／ 起動の流れとブートプロセス ／ systemdのターゲットとランレベル |
| パーミッションの読み方 ／ SUID・SGID・スティッキービット ／ iノードとリンク ／ FHS |
| パイプとリダイレクト ／ ジョブの状態遷移 ／ viのモード遷移 |
| パーティション（MBR / GPT） ／ マウントの考え方 |

### ノートを書き換えるには

`LinuC101_暗記まとめ.md` を編集し、次を実行して `notes.js` を作り直します。

```bash
powershell -ExecutionPolicy Bypass -File build-notes.ps1
```

図解を追加・変更する場合は `notes-view.js` の `NOTE_FIGURES` に、**見出し名をキーにして** SVG を書きます。その見出しの直後に自動で挿入されます。色は `.fig` のCSSクラス（`bx` `bx-a` `bx-g` `bx-w` `bx-r` `lbl` `mono`）を使うと、アプリのテーマに追従します。

## 機能

- **出題数を選べる** — 5 / 10 / 20 / 30 / 50 / 全問
- **カテゴリで絞り込み** — 主題1.01〜1.05を個別に選択
- **出題順** — ランダム / 番号順
- **弱点優先** — 累計成績で不正解率が高い問題から出題
- **即時解説** — 選択肢を選んだ直後に、正解・不正解にかかわらず正解と解説を表示。解説内のオプションには（英単語＝意味）の形で覚え方を併記
- **「不正解にする」ボタン** — 正解した問題を自分の判断で不正解として記録できる（まぐれ当たりの除外用）。押した後は「やっぱり正解にする」で戻せる
- **「正解（参照）」** — 解答前にコマンド表を開いた問題で正解した場合は、灰色の「○ 正解」として自力の正解とは別枠で記録される
- **スキップ** — 解答せず次へ進める（未回答としてカウント）
- **ホーム画面の進捗表示** — 全何問中、正解／不正解／未回答が何問かをバーと数値で表示
- **結果画面** — 正答率、全問の解答一覧（クリックで解説を展開）、間違えた問題だけ再挑戦
- **累計成績** — カテゴリ別の解答数・正解数・正答率
- **コマンドオプション早見表（右側ヘルプパネル）** — 下記参照

進捗と成績はブラウザの localStorage に保存されるため、閉じても「続きから再開」できます。

## コマンドオプション早見表

次のいずれの方法でも開けます。どの画面（ホーム／出題中／結果）でも利用でき、解答中でも開いたままにできます。

- 問題カード内の「コマンド表を開く」ボタン（解答前は「コマンド表を開く（不正解扱い）」と赤く表示）
- 画面右端の「コマンド表」タブ
- 画面右上の「コマンド表」ボタン
- `H` キー（`Esc` で閉じる）

パネル上部の「**次の問題でも開いたままにする**」チェックボックスで、次の問題へ進んだときの挙動を選べます。

| 状態 | 動作 |
|---|---|
| チェックあり（既定） | 開いたまま次の問題へ進む。そのため次の問題も参照扱い（不正解）になる |
| チェックなし | 次の問題へ進むと自動的に閉じる。開き直さない限り通常どおり採点される |

表は次の3列構成です。

| 入力するコマンド | 覚え方 | 実際の役割 |
|---|---|---|
| `-c` | create（作成） | 新しいアーカイブを作成する |
| `-x` | extract（取り出す） | アーカイブを展開する |
| `-f` | file（ファイル名） | 対象アーカイブのファイル名を指定 |

- **関連コマンドの自動表示** — 出題中にパネルを開くと、先頭に「この問題に関係するコマンド」として該当コマンドが**展開済み**で並びます（琥珀色で強調）。その下に「そのほかのコマンド」が続きます。問題を進めるたびに自動で入れ替わります。
- **検索** — コマンド名・オプション・覚え方・役割のどれでも部分一致で検索（日本語可）。一致箇所はハイライトされます。
- **グループ絞り込み** — ファイル操作／テキスト処理／パッケージ管理など11グループ。
- 検索中・グループ絞り込み中は関連セクションを出さず、通常の一覧を表示します。
- 画面幅が1250px以上のときは右側に固定表示され、問題を見ながら参照できます。狭い画面では引き出し（ドロワー）として開きます。

### 参照して正解したときの扱い（「正解（参照）」）

出題中にコマンド表を開くと、その問題には「コマンド表を参照しています。この問題は正解しても**「正解（参照）」**として、自力の正解とは分けて記録されます」という案内が出ます。

判定は次の4種類です。

| 表示 | 色 | 意味 |
|---|---|---|
| ○ 正解 | 緑 | 参照せずに正解 |
| ○ 正解 `コマンド表を参照` | **灰色** | コマンド表を見て正解 |
| ✕ 不正解 | 赤 | 誤答（参照の有無は問わない） |
| ― 未回答 | 濃い灰色 | スキップ／未到達 |

- 正答率は「自力で正解した割合」です。参照つきの正解は分母に含まれますが、正解としては数えません。
- ホーム・出題画面・結果画面のカウンタと進捗バーに、灰色の「正解（参照）」が独立して表示されます。
- 「できなかった問題だけ再挑戦」の対象には、不正解・未回答に加えて参照つき正解も含まれます。
- 判定は問題単位です。次の問題に進むとリセットされます。
- 途中で閉じても、その問題を「参照した」事実は取り消せません。
- パネルを開いたまま次の問題へ進んだ場合、その問題も参照扱いになります。避けたい場合は「次の問題でも開いたままにする」のチェックを外してください。
- **解答した後に開く分には影響しません。** 解説を読みながら参照しても判定は変わりません。

コマンドを追加・修正する場合は `commands.js` を編集します。

```js
{
  name: "コマンド名", group: "テキスト処理",   // group は HELP_GROUPS のいずれか
  keys: ["リダイレクト"],                      // 任意。日本語で問題と結び付けたいとき
  desc: "コマンドの概要",
  ex: "実行例",
  rows: [
    { opt: "-n", memo: "number（番号）", role: "行番号を付ける" }
  ]
}
```

関連コマンドの判定は、コマンド名に含まれる英字（`tar`、`mkswap` など）と `keys` の日本語キーワードを、問題文・選択肢・解説と突き合わせて行います。問題文に出てくるものほど上位に並びます。`file.txt` のようなファイル名に反応しないよう、前後がピリオドの場合は一致とみなしません。

## キーボード操作

| キー | 動作 |
|---|---|
| `1`〜`9` | 選択肢を選ぶ |
| `Enter` / `Space` | 次の問題へ（複数選択問題では解答する） |
| `H` / `?` | コマンドオプション早見表の開閉 |
| `Esc` | 早見表を閉じる |

## 問題を追加・修正するには

`questions.js` の `QUESTIONS` 配列に追記するだけです。

```js
{
  id: 97,                       // 他と重複しない数値
  cat: "1.03",                  // CATEGORIES のキー
  q: "問題文",
  choices: ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  answer: [1],                  // 正解のインデックス（0始まり）
                                //  要素1つ → 単一選択（クリックで即判定）
                                //  要素2つ以上 → 複数選択（「解答する」で判定）
  exp: "解説文"
}
```

カテゴリ自体を増やす場合は、同ファイル先頭の `CATEGORIES` にキーと名称を追加します。
